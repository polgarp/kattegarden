# Kattegården

A cat-yard maths game for one 9-year-old. Cats ask for beds, she builds them out of stickers, and multiplication happens on the way.

**Play:** https://polgarp.github.io/kattegarden/ (on iPhone: Share → Add to Home Screen first, then play from the icon)

Current state is a feel prototype: one cat, one request at a time, three ways to get it wrong (all of them funny).

- `index.html` is the whole game: no build step, no dependencies
- `STYLE.md` is the style bible and is authoritative
- `explore/` holds art-direction studies
